# M-XML Bench

An XML-aware three-way merge driver and workbench for git, built for Duck Creek manuscripts.

- **Download:** [Releases](https://github.com/RedlineIP/MXmlBench/releases). Betas are marked Pre-release.
- **User guide:** [redlineip.github.io/MXmlBench](https://redlineip.github.io/MXmlBench/)
- **Report a bug:** [open an issue](https://github.com/RedlineIP/MXmlBench/issues/new/choose) or email support@redlineip.com.

Issues are public. Never attach client manuscripts or other confidential files; email samples to support@redlineip.com instead. [Reporting bugs](https://redlineip.github.io/MXmlBench/start/reporting-bugs/) explains what is safe to post.

This repository holds releases and bug reports only; the source is not public. M-XML Bench needs a registration key from Redline Integration Professionals LLC. Use is covered by the [LICENSE](LICENSE).
