Merge XML by element, not by line.

M-XML Bench resolves git merge conflicts in Duck Creek manuscripts one element, one attribute and one table cell at a time.
Quick start

M-XML Bench has two parts that work together.

  • The XML merge driver runs inside git merge. It merges Duck Creek manuscripts, the files whose root element is <ManuScript>, by element identity, so a change to one field and a change to another field never collide just because they sit on nearby lines. Rate tables merge cell by cell. Only real disagreements are left as conflicts. Every other .xml file gets git’s normal line merge.
  • The Workbench is where you settle those. Open it with git mergetool or from your git client, and it shows ours, base and theirs next to the merged result, flags every place the driver made a choice, and lets you take a side per element or edit the result by hand. It checks the result before it writes the file back to git.
